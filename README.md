# 🍔 Food Delivery Time Predictor

Predicts food delivery time using XGBoost based on traffic, weather, distance and more.

## Live Demo
👉 [Try the app here](https://food-delivery-time-prediction-esthuxhcxwwrqwjjpakfwd.streamlit.app/)

## Results
- MAE: 3.81 minutes
- RMSE: 4.86 minutes
- R2: 0.73

## Features used
- Delivery person age and ratings
- Weather conditions
- Road traffic density
- Distance
- Type of order and vehicle
- Festival and city type
- Prep time and order hour

## How to run locally
pip install -r requirements.txt
streamlit run app.py

## Dataset
Kaggle food delivery dataset — 45,593 deliveries
